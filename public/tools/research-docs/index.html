为什么做它

调研这件事，最费的是人。

真正该花时间的，是判断和决策，不是翻网页。

「一搜就是大半天」

一个问题翻十几个网页，看完标题还没找到重点，时间全耗在「找」上。

「存了，但找不到」

收藏夹、网盘、备忘录各存一点，真要用时两眼一抹黑，只好重新搜一遍。

「整理完，就过时了」

辛苦整理的内容，过几天就追不上新动态——资料是死的，世界是活的。

研和讨把「找资料、做讨论、写文档」交给一支不下班的团队。

核心功能

你一句话，它们一整套

把一件课题从「想了解」推进到「有报告」，中间的活全自动。

一句话，建队开工

对页面底部的知识助手说一句「调研 XX，写份报告」，它自动拆成执行计划：谁查资料、谁论证、谁成稿，各就各位。

数字伙伴，随你捏

人设和擅长领域都由你定，公众人物还能一键自动生成。之后 @一下名字，活儿就派出去了。

开一场没人缺席的讨论会

指定主持人和参与伙伴，各方轮流发言、互相交锋，最后由主持人收束成一份结论报告。

定时任务，自动盯梢

「每周一调研一下竞品」——需求里带个时间词就行。到点自动开工，成果写回知识库，站内信汇报。

成果沉淀成知识库

文件夹五层嵌套，文档支持 md / html / csv 三种格式；每次创建、修改、移动都留档，随时可查。

干活全程，实时直播

每一步由谁执行、它的思考过程、调用了什么工具、产出了什么，全部实时流式展示，任务跑完还有汇报。
