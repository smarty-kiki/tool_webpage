⌃ ⌥ 哪个文件是季度报告？
为什么做它

AI 很聪明，只是够不着你的屏幕

它什么都知道，却点不了屏幕上任何一样东西——动手的永远是你。

「右上角那个按钮」

用文字描述屏幕上的位置，一句话打三十个字，对方还得猜。

指路的是它，找路的还是你

「先点设置，再进高级选项」——话说得很对，然后你还得自己找、自己点。

每天几十次一模一样的点击

打开、切走、点回来，同样的鼠标动作重复一整天，纯体力活。

Kiki 换了个活法：不描述，直接指——该动手时，还能替你动手。

核心功能

说句中文，剩下的交给它

回答、指路、点击、滚动、输入，都真实发生在你的屏幕上，每一步都看得见。

指给你看

「哪个文件是季度报告？」话一说完，紫色光标飞过屏幕，停在那个文件上——你得到的不是一段文字描述，是那个东西本身。

真的动手

单击、双击、三击、右键、四向滚动、拖拽，它都会。动手之前，光标先变红，还会带上你的鼠标一起过去——你看得见它要去哪。

多步任务，自己走完

一句话交给它一串操作：每做完一步，它重新看一眼屏幕，再决定下一步，最多连做 20 步。上下文自动折叠，面板上能看到它「脑子用了多少」。

边做边念

干活的时候它会出声念出来——念到哪一句，光标就停在哪个东西上。进度听得见，位置看得见。

录一遍，循环回放

一段重复操作：按 Shift+Option 录下你的鼠标动作，再按一下开始循环重放，第三下停下。「每天点三十遍」变成按一下。

命令行也能编排

懂命令行的话，语音那套都能写成脚本：kiki command 一次编排一串手势——11 个子命令（单击、双击、三击、右键、四向滚动、拖拽、输入、按键）不花一分钱；kiki screenshot、kiki locate 只读看屏幕，安静不动手。

它知道自己不该动手

越界的事，它宁可停下，也不硬来——鼠标和键盘的控制权，还有两个开关随时收回。

危险词不点

碰到「删除」「卸载」「格式化」这类词，它拒绝下手。

权限没给，不动

系统权限没给全，它宁可什么都不做，也不绕路。

说到一半，不算数

你还没说完就冒出来的请求，它挡回来，并告诉你原因。

⌘⇧⌫ 从不按

这类危险的系统快捷键，它从来不碰。

隐私与花费

你的屏幕，只在你的 Mac 上

该在本机做的，绝不往外送；要花钱的地方，只有一处。

离开你 Mac 的，只有截图和那句话

转写、朗读、抓屏、认字，全在你本机完成——不联网也能把话转成字。唯一的凭据是你自己的 DeepSeek API Key，锁在 macOS 钥匙串里；没有账号，也没有别人的服务器。

转写在本机 认字在本机 无账号、无服务器

花钱吗？只花你自己的用量

应用本体开源、不收费。语音、手势、命令行都不花钱；只有让模型动脑的时候，才走你自己的 DeepSeek 账号——用多少花多少。模型还能选：默认 Flash 快而省，V4 Pro 更聪明。

快速上手

三步，请它上岗

不用注册、不用登录——权限给完那一刻，就能开口说话。

1

下载

到 GitHub Releases 下载 Kiki 的最新安装包（.dmg），拖进「应用程序」。

2

放行一次

没做公证，首次打开 macOS 会拦一下——照提示放行一次就好。看到「已损坏」提示的，展开下面的说明。

3

给权限，填上 Key

面板会逐条告诉你缺哪项权限、现在走到哪一步；再把你的 DeepSeek API Key 填进去（存在钥匙串里）。就绪——按住 Control+Option 说话。

打开时提示「无法验证开发者」或「已损坏」？

这个应用没有 Apple 开发者证书、没有做公证，所以首次打开会被 Gatekeeper 拦一下。放行一次即可：

  1. 先双击打开一次，macOS 会提示无法验证开发者；
  2. 打开「系统设置 → 隐私与安全性」，在底部找到被拦的提示，点「仍要打开」。

或者，在终端执行一次这条命令，之后就能正常打开：

xattr -dr com.apple.quarantine /Applications/Kiki.app

还有一点：请始终从「应用程序」里双击启动（或者用 open -a Kiki）。直接运行程序文件的话，屏幕录制权限会算到终端头上，Kiki 反而拿不到。

常见问题

你可能想问

要花钱吗？

Kiki 本体不收费，MIT 协议开源。语音、手势、命令行都不花钱；唯一的开销是你自己的 DeepSeek 用量——Flash 很省，V4 Pro 更聪明，也更费一点。

它能看到我屏幕上的一切吗？

它只在需要的时候抓取屏幕来认字、找位置；离开你 Mac 的，只有截图和你说出的那句话。转写、朗读、抓屏、认字全在本机完成，不联网也能把话转成字。

要注册账号吗？

不用。没有账号、没有服务器、没有登录——唯一的凭据是你自己的 DeepSeek API Key，存在 macOS 钥匙串里。

它会不会误删我的东西？

危险操作它不点：碰到「删除」「卸载」「格式化」这类词会拒绝下手；权限没给全就不动；没说完的请求会被挡回来并说明原因。⌘⇧⌫ 这类危险快捷键更是从来不按，鼠标和键盘的控制权还有两个开关随时收回。

支持哪些 Mac？

macOS 14.2 及以上。Apple 芯片和 Intel 芯片都是同一个安装包（通用二进制）。

会开机自启吗？

不会。Kiki 刻意没做开机启动项——不用它的时候，它就不在。

怎么在命令行里用？

在面板里点一下按钮，会建好 /usr/local/bin/kiki 的软链接。之后 kiki command '…' 就能编排手势，kiki screenshot、kiki locate '确定' 只读看屏幕。
