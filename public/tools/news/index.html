你可能想问

它和让 Agent 自己搜新闻，差别在哪？

让 Agent 网搜，拿到的是未经整理的网页碎片：质量参差、叫法不一、新旧难辨，还得自己拼。纽斯是提前整理好的结构化新闻库——信息点拆好、叫法归组、时间分明、出处可查，Agent 一步就能拿到能用的答案。

新闻是从哪来的？

纽斯持续从一批新闻源收录文章，拆解成事实、观点、计划三类事件入库。目前收录了多少文章、多少事件，打开 news.yao-yang.cn 首页的看板就能看到实时数字。

skill 会不会悄悄过期？

不会。skill 每次使用前先校验版本；接口契约升级时会收到明确提醒，并按「更新协议」把电脑上所有相关副本一次更新到位，然后用新版本自动重试。
