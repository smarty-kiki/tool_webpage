为什么做它

用 Claude Code 的人，都懂

工具跑得很快，但你的注意力总被它牵着走。

「它是在思考，还是卡住了？」

盯着终端干等，分不清该继续等，还是该出手干预。

「切走之后，跑完了也不知道」

只能时不时回头瞄一眼终端——回个消息都不踏实。

「月底一看，token 都烧哪儿了？」

哪个项目花得最多、哪个模型是大头，完全没有概念。

WatchYourClaude 把这三个问题，都变成了一眼就能回答的题。

核心功能

菜单栏里的监控中心

不占 Dock、不弹窗口，安静地待在菜单栏里，随时待命。

每个会话，一目了然

正在运行的每个 Claude Code 会话都列在这里：忙还是闲、属于哪个项目。菜单栏图标本身就是状态灯——忙碌泛绿、空闲泛蓝、无活动是灰。

实时速度曲线

每秒吞多少 token、吐多少 token，实时画给你看。它跑得够不够快，曲线说了算。

token 消耗账本

最近 3 小时的消耗按 10 分钟一组画成柱状图，还能按项目和模型拆开看。哪个项目烧得最凶，清清楚楚。

干完活儿，叫你一声

开启通知后，会话一从忙碌转为空闲就响铃提示。放心去回消息、泡杯咖啡，活儿干完了它叫你。

数据不出你的 Mac

所有信息都只来自你本机的 Claude Code 会话记录，不上传、不收集、不偷偷联网。放心用。

开源，随时自己编译

MIT 协议，源码全部公开。想研究实现、想自己魔改，仓库随时欢迎。

快速上手

三步，开始用

不用配置、不用登录，下载就能跑。

1

下载最新版

到 GitHub Releases 下载 WatchYourClaude-x.x.zip，解压。

2

拖进「应用程序」

和其他 Mac 应用一样，拖进去就行。

3

打开，它就住进菜单栏

菜单栏上多了一枚会变色的小图标，点开就是监控面板。

打开时提示「无法验证开发者」？

这个应用没有 Apple 开发者证书、没有做公证，所以首次打开会被 Gatekeeper 拦一下。放行一次即可：

  1. 先双击打开一次，macOS 会提示无法验证开发者；
  2. 打开「系统设置 → 隐私与安全性」，在底部找到被拦的提示，点「仍要打开」。

或者，在终端执行一次这条命令，之后就能正常打开：

xattr -dr com.apple.quarantine /Applications/WatchYourClaude.app
常见问题

你可能想问

要花钱吗？

不花。WatchYourClaude 以 MIT 协议开源，也可以自己下载源码编译。

我的数据安全吗？

安全。应用只读取你电脑上 Claude Code 的本地会话记录，不上传任何数据，也不收集使用信息。

支持哪些系统？

macOS 14.0 及以上版本。

它会拖慢我的 Mac 吗？

不会。它是个轻量的菜单栏应用，安静地常驻角落，你几乎感觉不到它的存在。
