上手

三步，装好这枚把手。

1

下载，拖进应用程序

到 GitHub Releases 下载 dmg，把 NotchTasks.app 拖进「应用程序」。首次打开若被拦，右键点图标 →「打开」一次即可。

2

把手贴上屏幕右缘

启动后，一枚黑色把手出现在屏幕右边缘靠上的位置，不占 Dock、不弹窗口。WorkBuddy 和 Claude Code 的会话会自动出现。

3

扫过去，接着干活

鼠标扫过把手展开面板，点任务行直接跳回原处。之后该你出手时它会亮——平时，你都可以忘了它。

要给什么权限吗？会自启动吗？
不需要任何系统权限：全程只读、不改任何文件。唯一会弹的是系统通知权限——不授权也不影响把手本身的提醒，只是收不到系统通知。不会开机自启，想要的话到「系统设置 → 通用 → 登录项」手动添加 NotchTasks 即可。
常见问题

你可能想问

会读我的代码或对话内容吗？

不会。它只读任务的状态字段——标题、状态、工作目录、时间；不读会话正文，不读代码，也从不写任何东西。

打开被提示「无法验证开发者」？

安装包是 ad-hoc 签名（没有 Apple Developer ID），首次打开会被 Gatekeeper 拦下，这不是坏了。右键点图标 →「打开」一次即可，之后正常双击。

不用 WorkBuddy 也能用吗？

能。它同时盯两个来源：WorkBuddy 的会话和终端里的 Claude Code CLI，缺哪个就少看一块；两个都没有时，面板只是安静地空着，不会出错。

该看哪一个，让把手告诉你。
